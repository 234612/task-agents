# Skill: Advanced Market Research Search Strategy

## Description
当执行复杂的市场调研任务时，应用此搜索策略以提高信息获取的效率和准确性。

## Core Tactics

### 1. 关键词组合策略
不要只搜品牌名。使用以下组合公式：
- **找痛点**：`[产品名] + 缺点 / 吐槽 / 避雷 / 智商税`
- **找数据**：`[行业名] + 市场规模 / 增长率 / 研报 / filetype:pdf`
- **找竞品**：`[产品名] + vs / 替代 / 对比 / 评测`
- **找官方**：`[公司名] + investor relations / 财报 / site:official-domain.com`

### 2. 信源分级原则
- **Tier 1 (高可信)**：上市公司财报、政府统计局数据、权威咨询机构（Gartner, IDC）报告。
- **Tier 2 (中可信)**：知名科技媒体、垂直行业网站、高赞知乎/Reddit 深度回答。
- **Tier 3 (低可信)**：自媒体文章、百科词条、未经验证的论坛帖子（仅用于发现线索，不可作为数据源）。

### 3. 交叉验证机制
对于任何关键数据（如市场份额、融资额），必须找到至少两个独立信源佐证。如果冲突，以 Tier 1 信源为准，并在报告中注明差异。

### 4. 时间窗口控制
- **趋势类**：仅看近 6 个月数据。
- **基础事实类**：可放宽至近 2 年，但需标注时间。
